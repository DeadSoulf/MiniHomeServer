# MiniHomeServer — запуск на Debian 13

Версия 0.1 — рабочая локальная панель: вход, карта, редактор объектов и журнал. **Реальное управление физическими устройствами ещё не подключено.**

## Быстрая установка на минимальный Debian (без Docker)

Если Docker не установлен, используйте готовый установщик systemd. Он разворачивает панель с отдельным непривилегированным пользователем `minihome`, отдельным каталогом данных и просит задать пароль интерактивно. **Он не меняет SSH, firewall или другие службы.**

Выполнить в SSH-терминале:

```bash
su -
apt-get update
apt-get install -y git python3
git clone https://github.com/DeadSoulf/MiniHomeServer.git
cd MiniHomeServer
bash scripts/install-systemd.sh
```

Если репозиторий уже есть, повторно клонировать его не нужно. Скрипт проверяет, свободен ли локальный порт 8080, и не перезаписывает существующую службу `minihome.service`.

После успешной установки:

```bash
systemctl status minihome --no-pager
curl -fsS http://127.0.0.1:8080/api/health
```

Доступ с компьютера — через защищённый SSH-туннель, как описано ниже. Пароль не пишется в командную строку или историю терминала, файл с паролем хранится с ограниченными правами в `/etc/minihome/admin-password`.

> Установка systemd — альтернатива Docker, а не дополнение к нему. **Выберите один вариант.**

## Требования

Debian 13, Docker Engine и Docker Compose plugin. До установки следует проверить действующие службы и контейнеры: панель не должна мешать существующей системе.

## 1. Исходники (на Debian-сервере)

```bash
git clone https://github.com/DeadSoulf/MiniHomeServer.git
cd MiniHomeServer
cp .env.example .env
chmod 600 .env
```

Отредактируйте `.env` **на сервере**, задав уникальный пароль `MINIHOME_ADMIN_PASSWORD` длиной не меньше 12 символов. Не присылайте его в чат и не сохраняйте в GitHub. С пустым паролем Compose не запустится.

## 2. Запуск

```bash
docker compose up -d --build
docker compose ps
curl -fsS http://127.0.0.1:8080/api/health
```

По умолчанию HTTP доступен **только на 127.0.0.1:8080 сервера**. Публичных портов открывать не нужно.

Чтобы открыть панель в браузере своего компьютера через существующий SSH-доступ:

```bash
ssh -L 8080:127.0.0.1:8080 texnik@SERVER_IP
```

После этого откройте `http://127.0.0.1:8080`. Для постоянного удалённого доступа предпочтителен VPN или существующий HTTPS reverse proxy. При работе за HTTPS выставить `MINIHOME_COOKIE_SECURE=1`; нельзя публиковать административный HTTP напрямую в интернет.

## 3. Использование

1. Войдите паролем из `.env`.
2. Нажмите «Загрузить план» и выберите PNG/JPEG/WebP до 8 МБ.
3. Нажмите «Добавить объект», выберите точку карты, задайте тип, название и зону.
4. Включите «Редактировать» и перетаскивайте значки для изменения расположения.
5. Состояние оборудования останется «Нет данных», пока не будет настроено реальное подключение.

Состояния, карта и журнал сохраняются в SQLite в Docker-томе `minihome_data`. При обновлении карты координаты объектов сохраняются.

## 4. Обслуживание

```bash
docker compose logs --tail=100 -f
docker compose restart minihome
docker compose down
```

Команда `docker compose down` останавливает сервис, но сохраняет данные. **Не используйте `docker compose down -v`**, она удалит том и базу.

Обновление: сделать резервную копию базы SQLite и карты -> `git pull --ff-only` -> `docker compose up -d --build` -> проверить `/api/health` и панель. Для копирования активной SQLite использовать backup API SQLite либо остановить контейнер; простое копирование базы без WAL ненадёжно.

## 5. Режим быстрого теста без Docker

```bash
export MINIHOME_ADMIN_PASSWORD='СЮДА_СВОЙ_УНИКАЛЬНЫЙ_ПАРОЛЬ'
python3 server.py
```

Адрес `http://127.0.0.1:8080` на Debian. Это не служба автозапуска, а только ручной тест.

## 6. Проверка кода

```bash
python3 -m unittest discover -s tests -v
node --check static/app.js
```

## Границы версии 0.1

Поддержка MQTT, ESP32, Home Assistant, Frigate, сценариев и управляющих команд планируется как отдельные интеграционные модули. На данной стадии нет имитации телеметрии и нет возможности случайно включить отопление/открыть ворота. Панель не является системой безопасности или аварийного управления.
