# Доступ к MiniHomeServer с любого компьютера

## Прямой доступ по IP (0.0.0.0:8080)

MiniHomeServer может слушать `0.0.0.0:8080` на Debian, чтобы браузеры других компьютеров могли подключаться к нему.

**Если служба systemd уже установлена**, под root на Debian:

```bash
cd /root/MiniHomeServer
git pull --ff-only
bash scripts/enable-all-interfaces.sh
```

После успешной проверки:

- В сети Debian: `http://<LAN_IP>:8080`.
- Через внешний адрес: `http://<PUBLIC_IP>:8080` — **только при открытом TCP 8080 и корректном NAT/пробросе портов**.

Если `minihome.service` отсутствует, используйте `bash scripts/install-systemd.sh`: установщик также настроен на `0.0.0.0`. Он запросит новый отдельный пароль панели и не затронет SSH/firewall.

**Важное ограничение:** `0.0.0.0` — это адрес привязки веб-сервера, а не адрес для браузера. Открытие порта в интернет не происходит автоматически. Используйте IP сервера.

**Безопасность:** HTTP не шифрует пароль администратора. Перед публикацией в интернете настройте HTTPS с доверенным сертификатом или VPN. Не открывайте порт 8080 в интернет без защиты; в частной сети допустимо ограничить доступ маршрутизатором/межсетевым экраном. Управление физическими устройствами в версии 0.1 пока отсутствует.

## Альтернативный защищённый доступ через Termalin

Можно открыть панель через внутренний сайт MiniHomeServer в [кабинете Termalin](https://termal.in/account). Это не требует открытия входящих портов, но зависит от стабильности Connector. Войдите в свой аккаунт Termalin, выберите внутренний сайт MiniHomeServer, затем введите отдельный пароль панели.

## Если Docker вместо systemd

Привязка опубликованного порта задаётся в `.env`:

```env
MINIHOME_BIND_ADDRESS=0.0.0.0
MINIHOME_PORT=8080
```

После правки: `docker compose up -d`. Не запускайте параллельно системную службу и контейнер на одном порту.
