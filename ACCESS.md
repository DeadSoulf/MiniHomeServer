# Доступ к MiniHomeServer с любого компьютера

## Рекомендуемый вариант: защищённая ссылка через Termalin

Для MiniHomeServer в Termalin заведён внутренний сайт, указывающий на `http://127.0.0.1:8080` на сервере Debian.

Как это работает:

1. На сервере должна работать служба `minihome`.
2. На другом компьютере или телефоне войдите в **свой** аккаунт на https://termal.in/account.
3. Откройте в кабинете внутренний сайт **MiniHomeServer**.
4. Введите отдельный пароль панели MiniHomeServer.

**Не требуется:** SSH на компьютере, открытие портов 80/443, домен или внешний IP для приложения.

Termalin выдаёт отдельный `open_url` (открывает авторизованного пользователя через кабинет). Ссылку и доступ к кабинету не публикуем в открытом репозитории: её владелец получает в чате/кабинете. Допуск других пользователей к внутреннему сайту настраивается владельцем Termalin.

## Установка службы на Debian

Если служба ещё не установлена, в существующем SSH-терминале сервера один раз:

```bash
su -
apt-get update
apt-get install -y git python3
git clone https://github.com/DeadSoulf/MiniHomeServer.git /root/MiniHomeServer
bash /root/MiniHomeServer/scripts/install-systemd.sh
```

Установщик запросит **новый пароль для веб-панели**, который не совпадает с паролем SSH. Пароль вводится скрыто. Установка не меняет SSH и firewall и не открывает публичных портов.

Проверка на сервере:

```bash
systemctl is-active minihome
curl -fsS http://127.0.0.1:8080/api/health
```

Ожидаемый результат: `active`, затем JSON с `"ok":true`.

**Безопасность:** Termalin внутренний сайт доступен после аутентификации в кабинете, а приложение отдельно требует пароль. Само приложение слушает localhost. Не привязывайте его к `0.0.0.0` без пересмотра защиты.

## Ограничения

- Если Termalin Connector офлайн, ссылка временно не сможет открыть приложение.
- Установка и запуск на Debian должны быть завершены прежде, чем ссылка покажет панель.
- Сервис Termalin может требовать отдельной настройки доступа для другого пользователя; совместное использование личной учётной записи не рекомендуется.

Другие варианты — личный VPN или HTTPS с аутентификацией на домене. Они не обязательны для первой версии.
