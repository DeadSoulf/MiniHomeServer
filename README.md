# MiniHomeServer

**Версия 0.3.0 — обнаружение локальных устройств и чтение Zigbee2MQTT на Debian 13.**

Карта участка, объекты, зоны и история изменений без облачной зависимости и без фиктивных показаний. Репозиторий ведётся в ветке `main`.

## Уже работает в коде

- **Территория:** загрузка плана PNG/JPEG/WebP, размещение объектов кликом и изменение координат перетаскиванием.
- **Оборудование:** каталог объектов (дом, котельная, камера, освещение, ворота, датчик, реле), группы/зоны, добавление, редактирование, удаление.
- **События:** журнал действий и изменений карты.
- **Настройки:** сведения о локальном сервере и подготовка к подключениям.
- **Backend:** Python без внешних зависимостей, JSON API, SQLite, пароль, ограничение попыток входа, session cookie, CSRF-защита.
- **Инфраструктура:** Docker Compose или отдельная служба systemd, привязка к 0.0.0.0:8080 по запросу владельца, тесты API и GitHub Actions.
- **Обновления:** для systemd — проверка GitHub и ручная установка из веб-интерфейса с резервным копированием, контролем SHA и откатом.
- **Устройства сети:** обнаружение LAN по ARP, mDNS и SSDP, IP/MAC и время последнего обнаружения, список сетевого оборудования без демоданных.
- **Zigbee:** отдельный список подключённых устройств через MQTT Zigbee2MQTT в режиме только чтения; для прочих типов шлюзов требуется отдельный адаптер.

**Важно:** состояния реального оборудования пока не считываются. Все новые объекты имеют статус «Нет данных», управление исполнительными устройствами не предусмотрено до интеграции.

## Запуск на Debian

Подробная инструкция для Docker **или минимального Debian без Docker**: [DEPLOY.md](DEPLOY.md). Поиск устройств и настройки Zigbee: [NETWORK.md](NETWORK.md). Обновления без SSH после первичной настройки: [UPDATES.md](UPDATES.md). Доступ по IP или через Termalin: [ACCESS.md](ACCESS.md). Готовый установщик systemd: [scripts/install-systemd.sh](scripts/install-systemd.sh).

```bash
git clone https://github.com/DeadSoulf/MiniHomeServer.git
cd MiniHomeServer
cp .env.example .env
chmod 600 .env
# Укажите в .env уникальный MINIHOME_ADMIN_PASSWORD длиной от 12 символов
docker compose up -d --build
docker compose ps
```

После запуска панель привязывается к `0.0.0.0:8080`. В локальной сети откройте `http://0.0.0.0:8080`. Доступ по внешнему IP `0.0.0.0:8080` требует отдельной настройки firewall/NAT. **Для доступа через интернет необходим HTTPS или VPN: HTTP передаёт пароль без шифрования.**

Для уже установленной systemd-панели первое включение веб-обновлений выполняется однократно: `bash scripts/enable-web-updates.sh` от root после `git pull --ff-only`. После этого обновления устанавливаются из раздела «Настройки». См. [UPDATES.md](UPDATES.md).

Выполнить тесты:

```bash
python3 -m unittest discover -s tests -v
node --check static/app.js
```

## Архитектура

```text
Browser (карта, объекты, события)
          │ HTTPS / localhost
          ▼
Python HTTP API ── SQLite + изображение карты
          │
          └── будущие отдельные адаптеры MQTT / Home Assistant / Frigate
```

Структура:

- `server.py` — API, безопасность, хранение данных.
- `static/` — интерфейс, CSS, логика карты.
- `compose.yaml`, `Dockerfile` — контейнер и конфигурация.
- `tests/` — проверки API, объектов, карты и авторизации.
- `AGENTS.md` — инструкции разработчикам и AI-агентам.
- `CHANGELOG.md` — изменения по датам.
- `scripts/update_worker.py`, `scripts/enable-web-updates.sh` — отдельный привилегированный обновитель и его однократное подключение.
- `NETWORK.md` — поиск LAN, подключение Zigbee2MQTT и ограничения протоколов.
