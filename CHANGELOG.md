# История изменений

## 2026-11-07 — v0.2.0: обновления из веб-панели

- В «Настройки» добавлены проверка GitHub и кнопка ручной установки новой ревизии из ветки main.
- Добавлен защищённый API обновления: обязательная сессия, CSRF и проверка точного SHA, без выполнения shell-команд из веб-процесса.
- Добавлены root-owned systemd units minihome-update.path/service и ограниченный до фиксированного GitHub-источника обновитель.
- Служба делает снимок SQLite и предыдущих файлов, проверяет целостность и синтаксис кода, обновляет файлы, проверяет /api/health и откатывает код при сбое.
- Добавлено обнаружение незаписанных локальных правок через SHA256-манифест, чтобы их не затереть обновлением.
- Сессии администратора теперь хранятся в SQLite, поэтому перезапуск приложения не обязан прерывать вход.
- Установщик systemd включает обновления при новой установке; для существующей установки добавлен однократный scripts/enable-web-updates.sh.
- Добавлены тесты API обновления, CSRF, SHA и манифеста, а также документация UPDATES.md.
- Изменения опубликованы в GitHub. **Развёртывание на Debian ещё не подтверждено**: прямой Termalin-доступ со стороны ассистента недоступен.


## 2026-11-07 — сетевой доступ по запросу владельца

- Установщик systemd переведён на прослушивание `0.0.0.0:8080`.

- Для Docker Compose задана привязка `0.0.0.0:8080`; настройки `.env.example` и документация синхронизированы.
- Обязательная авторизация не отключалась; HTTPS/ограничение firewall необходимы для безопасного доступа из интернета.
- Изменения в GitHub готовы; выполнение скрипта на Debian ещё не подтверждено, Termalin недоступен.



## 2026-11-07 — v0.1.0 (первый рабочий MVP)

- Создан сервер на Python (без внешних Python-зависимостей): HTTP API, вход администратора, CSRF-защита, временные сессии и ограничение попыток входа.
- Добавлена база SQLite для объектов, координат, настроек карты и реальных событий конфигурации.
- Добавлена русскоязычная адаптивная веб-панель: «Территория», «Оборудование», «События», «Настройки».
- Добавлен редактор карты: загрузка PNG/JPEG/WebP, создание объектов, выбор точки размещения и перенос значков.
- Отдельная безопасная модель: все объекты изначально «Нет данных»; реле, отопление, камеры и ворота не получают команд до подключения проверенных интеграций.
- Добавлены Dockerfile, Compose с привязкой к localhost, пример безопасной конфигурации и инструкция по установке на Debian.
- Добавлены интеграционные API-тесты и проверка через GitHub Actions.
- **Установка на реальный Debian пока не производилась:** доступ Termalin нестабилен.
